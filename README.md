# odin-Landing-Page

Hi! Just completed the CSS part in TOP Foundations :) 

This is my solution to the **Landing Page project** from [The Odin Project's Foundations Course](https://theodinproject.com). The goal of this project was to build a responsive, visually appealing landing page from scratch using HTML and CSS (specifically focusing on **Flexbox**).

## 🚀 Live Demo
👉 [View the Live Project Here](https://yash259-code.github.io/odin-Landing-Page/)

## 🛠️ Built With
- **HTML5** - Semantic markup
- **CSS3** - Custom styling and layout
- **CSS Flexbox** - For structural alignment and responsiveness

## 🧠 What I Learned
While building this project, I strengthened my understanding of:
- Using **Flexbox** to align elements dynamically (justify-content, align-items).
- Managing CSS file structure and keeping code clean.
- Balancing layouts using padding, margins, and border-radius.
- Selecting and implementing web fonts.
